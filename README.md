# 1. Spectroscope
Вопрос по выбору

Изучение дифракционной решётки с помощью самодельного спектроскопа

По итогу работы собрали спектроскоп на основе дифракционной решётки и нашли периоды дифракционных решеток.

В репозитории представлены фотографии, графики работы, а также tex файл (Spectroscope.tex) и конечный результат в виде pdf (Spectroscope.pdf). Также здесь есть код (Spectroscope.py) для анализа спектра.

# 2. Навигация по Spectroscope.py

Код представляет из себя простейшую программу для анализа цветовой составляющей спектра (синий, красный, зеленый) и относительной интенсивности. 

Для нормировки изображения по середине кадра можно использовать кнопку l, r позволяет выделить часть кадра, так что при нажатии enter работа будет идти с выделенной частью экрана, кнопка a дает 
возможность проанализировать спектр.
